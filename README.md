# Música até o Fim

App Android que trava o toque na tela enquanto uma música toca no YouTube Music
e destrava sozinho quando ela termina, para a criança escolher a próxima.

- Barra de progresso grande mostra quanto falta.
- No fim da música, pausa a próxima que começaria sozinha (pode desligar nos ajustes).
- Saída para os pais: segurar o canto superior direito da tela por 5 segundos.

## Baixar
Cada vez que o código muda, o GitHub gera o APK automaticamente.
Link fixo da versão mais nova:
`https://github.com/<usuario>/<repositorio>/releases/latest/download/MusicaAteOFim.apk`

## Configurar no celular
1. Instale o APK (aceite "instalar de fontes desconhecidas" / "instalar mesmo assim").
2. Abra o app → Passo 1: permitir acesso às notificações.
   Se estiver cinza: Configurações > Apps > Música até o Fim > ⋮ > Permitir configurações restritas.
3. Passo 2: permitir sobrepor outros apps.
4. Recomendado: Fixação de tela no YouTube Music.
